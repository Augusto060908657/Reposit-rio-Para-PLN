# Iluminação pública
Lâmpada queimada, poste apagado ou rua escura são pedidos pelo serviço de iluminação pública do SP156. Informe a rua, o número do poste, se houver uma placa nele, ou um ponto de referência próximo.
Quanto mais exata a localização, mais rápido a equipe encontra o poste. Informe se são vários postes seguidos apagados.
O Zelador não sabe o prazo exato do reparo. Acompanhe pelo protocolo no SP156.
Fio de energia caído ou soltando faísca é perigo: afaste-se e ligue para os Bombeiros, 193.
